# Fotos y videos de servicios

Cada servicio tiene su propia carpeta. Sube dentro las fotos o videos reales del trabajo:

- `mecanica-general`
- `mecanica-rapida`
- `frenos`
- `reparacion-motor`
- `alineacion-computarizada`
- `balanceo`

La imagen principal debe llamarse `portada.jpg`, `portada.png` o `portada.webp`. Las demás pueden llamarse `02-trabajo.jpg`, `03-resultado.jpg`, etc.

Se admiten imágenes JPG, PNG, WebP y GIF, y videos MP4 o WebM. GitHub actualizará la galería automáticamente después de cada cambio.

No elimines ni cambies el nombre de `servicio.json`.
